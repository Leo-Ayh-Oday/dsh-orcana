# @orcana/dsh-orcana-linux-bundle

Profile bundle for [@orcana/dsh-orcana-linux](../dsh-orcana-linux): activates
the hardening plugin with sensible defaults (1 GiB RLIMIT_AS, 64 tasks, no
egress) via the `dsh.bundle.patch` contract. See the
[install script](../../scripts/install-orcana-linux.sh) for a ready-made
profile.
